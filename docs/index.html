Control a whole Android phone farm from one window

Evelin mirrors every USB-connected Android device in a live grid, repeats your taps on all selected phones, and replays recorded automation scenarios across the farm. Free, open source, no root.

Features

Live screens

Every connected device in one grid, streamed via scrcpy 3 (H.264) and hardware-decoded with WebCodecs.

Mouse control

Click and drag to tap and swipe, scroll with the wheel, right-click for Back. Text input works in any language.

Broadcast input

A tap or key press on one selected phone is repeated on every selected phone at the same moment.

Action recording

Record with a finger on the phone or with the mouse on its tile. Taps, swipes, keys, text and pauses become a scenario.

No-code scenarios

Loops, random pauses, every-N-th-run steps, nested scenarios, “wait for text” and “tap on text” steps. Import and export as JSON.

Batch ADB actions

Install an APK, launch or clear apps, take screenshots, reboot or run adb shell on many devices in one click.

Per-device proxies

Round-robin HTTP proxies from a file or the CyberYozh API, applied through Android's system proxy, with an IP check per device.

Safe by design

Sandboxed renderer, strict IPC validation, escaped shell arguments, encrypted credentials and checksum-verified auto-updates.

Who it's for

  • QA teams running manual and regression tests on many Android models and screen sizes at once.
  • Device labs where one person looks after a rack of test phones.
  • Repetitive phone tasks: record once, replay on every device with randomised pauses.
  • Bulk device administration: APK installs, app resets, screenshots and reboots across the farm.

Get started in a minute

  1. Install Android platform-tools so adb is available.
  2. Enable USB debugging on each phone and connect them through a USB hub.
  3. Download Evelin, open it and accept the RSA prompt on every phone.

FAQ

How do I control several Android phones from my computer at once?

Connect them over USB, enable USB debugging and open Evelin. Select the devices and turn on Broadcast input: a tap or key press on one of them is repeated on all of them.

Do the phones need to be rooted?

No. Evelin uses standard ADB and the scrcpy server, which run with normal USB-debugging permissions.

How is Evelin different from scrcpy?

scrcpy mirrors one device per window. Evelin runs scrcpy for every connected device in a single window and adds broadcast input, action recording, scenarios, batch commands and proxy management.

Can I automate taps and swipes without writing code?

Yes. Record the task and it becomes a scenario you can edit, loop and run on any set of devices. Coordinates are stored as a percentage of the screen, so one scenario works across resolutions.

How many devices can it handle?

That depends on your USB hubs and CPU. Lower the stream resolution, bitrate or FPS in Settings to fit more devices on one machine.

Is it free?

Yes. Evelin is open source under the MIT license.
